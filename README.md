# 5ceco-sitev2

Static GigaCarbon marketing site. The homepage explains the operational-evidence direction through the synthetic FN128 fleet-maintenance case and a local Review Workbench capture. Earlier fuel reconciliation and Route Proof research, including corrections and negative results, remain under `/archive/`.

This repository contains website files, not the Workbench runtime or verified hosting credentials. The capture in `assets/workbench/` comes from the local synthetic test fixture.

For local review, serve the repository root with a static HTTP server, such as `python3 -m http.server 8766`, and open `http://127.0.0.1:8766/`.
